# Multi-Agent AI Systems Project Using CrewAI

## Build a Crew to Create Web Applications

This project demonstrates a **Multi-Agent System for Web Application Development**, providing a skeleton for collaborative and intelligent web application design.

---

## Getting Started

### Prerequisites

If you're running this notebook in an environment where the required libraries are not pre-installed, you can install them using the following command:

```bash
pip install crewai==0.28.8 crewai_tools==0.1.6 langchain_community==0.0.29
```

---

### Running the Project

1. Clone this repository:
   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Open the Jupyter Notebook:
   ```bash
   jupyter notebook Web_application_crew.ipynb
   ```

4. Follow the instructions provided in the notebook to build and simulate the multi-agent system for web application development.

---

## Features

- **Multi-Agent Collaboration:** Utilize intelligent agents to assist in web development.
- **Extensible Framework:** Easily integrate additional tools and agents for expanded functionality.
- **User-Friendly Interface:** The notebook serves as both the implementation and an interactive guide.

---

## Libraries and Tools

This project leverages the following libraries:

- **CrewAI (v0.28.8):** For agent orchestration and management.
- **CrewAI Tools (v0.1.6):** Supplementary tools to enhance agent functionality.
- **LangChain Community (v0.0.29):** Facilitates interactions and integrations with language models.
